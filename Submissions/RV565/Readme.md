## Description

RV565 is a video container for microcontrollers driving RGB565 SPI displays
such as the ST7789. A 12-byte little-endian header (magic `RV5`, version,
width, height, frames per second, flags, frame count) is followed by one
record per frame: a 32-bit little-endian payload length and a zlib stream
that inflates to exactly width × height × 2 bytes of big-endian RGB565
pixels. Frames are independent of each other, so any frame can be decoded on
its own, and the stored payload lengths allow decode time to be predicted
before playback. There is no audio track. Files are typically created on a
computer (Python tool, in-browser converter) and played on ESP32 or RP2350
boards.

## New Signature

RV565 Video, version 6 \
BOF ```52563506{4}[01:1E]{7}78```

| Bytes | Meaning |
| --- | --- |
| `52 56 35` | ASCII `RV5` |
| `06` | container version 6 |
| `{4}` | width and height (u16 each) |
| `[01:1E]` | frames per second, 1–30 |
| `{7}` | flags (1 byte), frame count (2), first frame length (4) |
| `78` | zlib header of the first frame (CMF byte: deflate, 32 KiB window) |

Flags are left out of the signature because readers must ignore unknown bits.
