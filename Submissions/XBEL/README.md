Hello, here's an old format that somehow never made it into PRONOM. Development signature and example file attached. Please let me know if there is anything else I can do.

**Format name**

XML Bookmarks Exchange Language 

**Version number**

Version 1.0

**Extensions**

xbel

**MIME/Media Type**

none

**Description**

A file format to store and exchange browser bookmarks/URLs.

**Format type**

Text (Mark-up)

**Vendor**

Designed by the [Python XML Special Interest Group](https://web.archive.org/web/20060220194548/http://www.python.org/sigs/xml-sig/) on the group's mailing list. Used by a variety of bookmark syncing applications.

**File format identification signatures**

XML Declaration, then mandatory identifier:
`+//IDN python.org//DTD XML Bookmark Exchange Language 1.0//EN//XML`

**Relevant links, documentation, extra information**

Specification:
https://pyxml.sourceforge.net/topics/xbel/docs/xbel.pdf.gz
